# Export des Claude-Artefakts „TA-Cockpit Messanlage“ (20.11.2026)

Vollständiger Export aller 15 Sammlungen der Artefakt-Datenbank (https://claude.ai/artifact/LZiNTP2ktcUetHv3DgQAVK), bevor das claude.ai-Projekt aufgeräumt wird.
Maßgeblich sind die Daten in `cockpit/daten/*.json`. Dieser Export ist nur ein Archiv, z. B. für
- `sensors.json`: die Websuche-Liste aus Chat 05 (s01–s20, 07./12.11.), die im Cockpit durch den Sensorvergleich aus Datenblättern ersetzt wurde,
- Einträge, die im Repo bewusst gelöscht wurden (z. B. deadlines d02, d06; tasks t17),
- `files.json`: Archiv-Metadaten mit Asset-IDs (die Dateien selbst liegen in `docs/archiv` bzw. vertrauliche nur auf dem PC),
- `tools.json`: morph (Morpho-Kasten-Stand im Artefakt), pcsync, cfbundle, eval.
